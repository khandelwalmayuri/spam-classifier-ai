# Spam Message Classifier (AI Project)

This is a beginner-friendly AI project that classifies SMS messages as **Spam** or **Not Spam** using Machine Learning.

## 🔧 Tech Stack
- Python
- Pandas
- Scikit-learn

## 📌 Features
- Text preprocessing
- Machine Learning model (Naive Bayes)
- Spam prediction with high accuracy

## ▶ How to Run
1. Install dependencies:
   pip install pandas scikit-learn

2. Run the project:
   python spam.py

## 🎯 Learning Outcome
- Basics of Machine Learning
- Text vectorization
- Model training and prediction
